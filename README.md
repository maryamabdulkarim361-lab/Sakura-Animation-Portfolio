# Sakura Animation Portfolio 🌸 — Maryam Abdul Karim

An interactive 3D portfolio featuring a cinematic 240-frame Canvas hero, pointer and touch rotation, obsidian/crimson/burgundy/amber palette, parallax depth, 3D rotating skill drum, stacking dossier cards, spinning seals, and responsive layout.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Vanilla CSS, Modern CSS Custom Properties
- **Animation**: Framer Motion, Lenis Smooth Scroll
- **3D & Canvas**: Three.js, Canvas frame scrubber, WebGL fog backdrop

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/maryamabdulkarim361-lab/Sakura-Animation-Portfolio.git
   cd Sakura-Animation-Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the application.

4. **Production Build**
   ```bash
   npm run build
   npm run start
   ```
